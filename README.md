# ⚔️ Ace of Conquest

Simulador de conquista por turnos sobre un mapa hexagonal, con gráficos animados en canvas.

## Cómo jugar

Abre `index.html` en tu navegador (no requiere instalación ni servidor).

- **▶ Paso**: avanza un turno.
- **⏵ Auto**: simulación automática (ajusta la velocidad con el deslizador).
- **↺ Reiniciar**: comienza una nueva partida.

## Reglas

- Cuatro imperios comienzan en las esquinas del mapa, cada uno con su capital 🏰.
- Cada turno los territorios generan tropas (las capitales generan más).
- Los imperios se expanden hacia territorios vacíos y atacan a sus vecinos.
- El terreno y las capitales dan bonificación defensiva.
- Gana el imperio que conquiste todo el mapa.

## Tecnología

HTML5 Canvas + CSS + JavaScript puro, sin dependencias.
